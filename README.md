# java-practica

Pista de práctica de codificación Java 21 (funcional y reactivo).

| Semanas | Módulo | Fase |
|---|---|---|
| 1–3 | `funcional-katas` | Katas funcionales sobre transacciones |
| 4–5 | `procesador-extractos` | Mini proyecto funcional |
| 6–8 | `reactor-fundamentos` | Project Reactor puro |
| 9–11 | `webflux-api` | WebFlux + R2DBC vs MVC + virtual threads |

## Reglas

- Código escrito desde cero: sin copiar y pegar, con el autocompletado de IA apagado.
- Cada kata se cierra con tests en verde.
- Un commit por kata: `kata-NN: descripción`.

## Ejecutar

Desde IntelliJ: panel Maven → `java-practica` → Lifecycle → `test`.
También puedes usar clic derecho sobre una clase de test → Run.
